# CFP · Panel desde afuera

Panel para ver y manejar una pileta con el **Control de Filtrado de Piletas (WiFi)** desde cualquier lugar.

- Es una página sin claves adentro. Cada persona escribe la suya y queda guardada solo en su navegador.
- Se conecta cifrado al intermediario MQTT. El equipo revisa cada orden: desde afuera **nunca** se puede encender la bomba, tocar la protección, instalar firmware ni cambiar el WiFi o las claves.
- Este repositorio se genera automáticamente; no se edita a mano.
